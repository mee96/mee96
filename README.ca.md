## <img src="https://api.iconify.design/ph/user-circle-fill.svg?color=%23FF6FA8&height=24" height="22"> &nbsp;Sobre mi
Soc desenvolupadora **Full Stack** centrada en **Angular, TypeScript, Python i FastAPI**.

Construeixo aplicacions web de principi a fi: **frontend, APIs REST, bases de dades, autenticació, aplicacions en temps real, integracions amb IA i desplegament cloud**.

Actualment treballo com a **Junior Web Developer a Fundació Esplai – Talent IT**, on desenvolupo aplicacions full stack i solucions híbrides amb Angular, FastAPI, Python, MySQL i Ionic.

M'interessa especialment crear **aplicacions en temps real, productes amb IA/RAG i experiències mobile-first**.

Abans de dedicar-me al desenvolupament vaig treballar durant tres anys com a **tècnica de laboratori**, una experiència que va reforçar el meu pensament analític, la precisió, la resolució de problemes i l'atenció al detall.

### Què construeixo
- Aplicacions web full stack i responsive
- APIs REST i aplicacions CRUD
- Aplicacions en temps real amb WebSockets
- Integracions amb LLM i sistemes RAG
- Aplicacions PWA i mobile-first
- Autenticació i gestió d'usuaris
- Aplicacions connectades a bases de dades SQL
- Desplegament de frontend i backend al cloud
